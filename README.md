<h1 align="center">ShotAI</h1>

<p align="center">

ShotAI 将本地对话、文件解析、知识库、图片理解、图片创作、模型管理和局域网访问集中在一个入口中，并提供 Windows Electron 客户端。模型权重和大型运行组件不随源码仓库发布。

请从 [完整项目说明](docs/README.md) 开始了解已实现能力、使用方法、模型选择、部署边界与后续计划。
