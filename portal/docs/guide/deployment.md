# 内网部署

## 基本方式

在负责运行的 Windows 主机上启动 ShotAI，主机统一运行模型与图片运行组件；同一局域网内的其他电脑使用浏览器打开主机显示的地址即可。

客户端不需要安装 Node.js、Ollama 或模型。请只在可信网络中使用，不要把 9090、`/ollama` 或 `/image` 直接暴露到公网。

## 模型准备

图片理解通常需要主模型与同版本的 `mmproj` 配套文件；图片创作除了模型文件，还需要可用的图片运行组件及其扩散模型、文本编码器、VAE 等配置。

优先从 Hugging Face 和模型官方 GitHub 获取模型，并确认授权、量化格式和配套文件。仓库不提供模型权重，也没有内置网盘下载入口。

## 并发建议

当前没有写死的用户数量上限，但也没有主机级任务队列、显存配额或并发限制。实际容量取决于 GPU 显存、内存、模型大小、上下文长度以及是否同时生成图片。

对于 RTX 4070 Ti 这类主机，建议先从少量并发任务开始测试；正式部署前应以自己的模型组合和真实任务压测为准。
