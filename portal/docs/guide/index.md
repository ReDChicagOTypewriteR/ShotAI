# 开始使用

ShotAI 把本地模型、文件解析、知识库、图片理解、图片创作和局域网访问放在同一个入口中。它适合希望在自己的设备或受控内网中使用 AI 的个人和团队。

## 先选择你的目标

- 想了解项目：阅读[产品概览](/guide/overview)。
- 想在 Windows 上直接使用：阅读[快速开始](/guide/quick-start)。
- 想让同一内网的其他电脑访问：阅读[内网部署](/guide/deployment)。
- 遇到模型或存储问题：阅读[常见问题](/guide/faq)。

## 一句话理解

一台主机负责运行 Ollama 和图片运行组件，其他电脑只需浏览器即可继续工作。ShotAI 不是公网 SaaS，不提供账号、多租户或云端数据同步。
