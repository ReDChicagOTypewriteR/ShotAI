# ShotAI 1.3.0

Windows 与 Ubuntu 统一更新，作为实机测试预发布提供。

## 更新内容

- 将 Excel、Word、PDF 能力整合进聊天，取消单独 Skill 调用入口。
- 增加模型体检与实际加载检测，区分 CPU、GPU 和混合加载。
- 优化五客户端公平排队、动态并发与图片任务调度。
- 完善模型导入错误提示、重试、桌面日志与诊断导出。
- 完整模型清理由服务端执行，增加冲突保护和中断状态记录。
- 优化生成与取消状态反馈，移除桌面宠物。
- 拆分部分前后端模块，补充故障测试和安装资源体积检查。
- 精简运行组件：保留 Ollama CUDA 12，图片组件改为可选扩展。

安装包不包含模型权重和 NVIDIA 驱动。升级保留原有数据与配置。

## 测试状态

本地构建和自动化回归不代替 Windows / Ubuntu 实机验证。请重点测试模型导入、CUDA 实际加载、多人并发、停止任务、文件生成与修改、完整清理、内网监控登录及覆盖升级。

真实 GPU 停止确认、真实子进程崩溃与完整安装升级测试仍待验证；设置页、文件任务与剩余服务拆分尚未全部完成。
