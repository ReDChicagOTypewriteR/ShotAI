# ShotAI 使用手册

这份说明面向第一次接触本地 AI 的使用者。日常使用不需要命令行，也不需要理解模型运行原理。

## 一、主机管理员第一次启动

1. 解压完整发布包，不要只复制其中的 `web` 文件夹。
2. 双击 `start-windows.bat`，出现系统询问时允许管理员权限。
3. 保持启动窗口开启，在主机浏览器打开 `http://127.0.0.1:9090`。
4. 如果已经安装聊天模型，页面会自动显示；没有时，在主机“设置 → AI 能力 → 日常对话”中添加。
5. 需要生成图片时，打开输入框左侧“+ → 创作图片”，选择下载好的模型文件。单文件版选择一个文件；三文件版一次选中三个文件。

其他电脑访问启动窗口显示的 `http://主机IP:9090`。它们不需要安装 ShotAI、Node.js、Ollama 或模型。

## 二、日常对话

- 在底部输入问题，按 Enter 发送；Shift+Enter 换行。
- 回答过程中可以点击停止，也可以向上滚动查看旧内容。
- 每条问题可以编辑后重新回答；每条回答可以复制或重新生成。
- 左侧用于新建、切换、重命名和删除对话。

## 三、图片和文件

- 点击输入框左侧“+”，选择图片或文件。
- 上传图片时，ShotAI 会自动寻找能够看图的模型，不需要手动切换当前聊天模型。
- 支持 PNG、JPEG、WebP、TXT、Markdown、PDF 和 DOCX。
- 旧版 DOC 请先在办公软件中另存为 DOCX；扫描版 PDF 暂时不能自动读出图片中的文字。

## 四、我的资料

1. 点击“+ → 我的资料”。
2. 新建资料夹并添加文件。
3. 打开需要用于回答的资料夹。
4. 回到对话直接提问，回答下方会显示参考文件。

“资料查找设置”是可选项。没有安装查找助手时，普通文字查找仍然可以使用。

## 五、创作图片

1. 点击“+ → 创作图片”。
2. 写下画面要求并选择图片形状。
3. 点击“开始生成”；不想继续时可以停止。
4. 完成后可以预览和保存。最近 12 张图片保存在当前浏览器中，可在图片页面重新打开。

聊天模型和图片模型由 ShotAI 自动分开使用，创作图片不会改变当前对话模型。

## 六、主机管理与内网使用

- 主机浏览器显示“主机管理模式”，可以添加和删除模型。
- 其他电脑显示“内网使用模式”，可以对话、读文件、使用资料和创作图片，但不能修改主机模型。
- 如确实需要允许内网电脑管理，可将 `lan.config.json` 中的 `allowLanAdministration` 改为 `true`；不建议在普通办公环境开启。

## 七、常见问题

### 本机能打开，其他电脑打不开

确认主机启动窗口没有关闭，访问的是主机内网 IP，并允许了 Windows 防火墙中的 9090 端口。

### 页面是旧内容或出现黑块

在“设置 → 清理与刷新”点击“立即刷新”，或按 Ctrl+F5。升级时必须替换完整 `web` 文件夹。

### 模型显示正常，但发送后报错

先在主机打开 `http://127.0.0.1:9090/healthz`。如果状态不是 `ok`，重新启动 ShotAI 和 Ollama。

### 图片模型导入后不能使用

确认三文件模型一次选择了完整的三个文件。网页会自动重新载入；如果提示需要重启，关闭启动窗口后重新双击 `start-windows.bat`。

### 如何清理本地记录

打开“设置 → 清理与刷新”，可分别清空对话、资料和生成图片记录。删除的是当前浏览器记录，不会删除主机模型。
