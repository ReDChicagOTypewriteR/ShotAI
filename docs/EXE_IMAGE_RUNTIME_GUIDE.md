# ShotAI Windows 可选图片组件 · CUDA 12

这个包用于给 ShotAI Windows EXE 增加“创作图片”功能，适合支持 CUDA 12 的
NVIDIA 显卡。包内不含图片模型，因此仍需自行准备模型文件。

## 安装方法

1. 先退出正在运行的 ShotAI。
2. 解压本包，把其中的 `runtime` 文件夹复制到 ShotAI 主目录并选择合并。
3. 确认 `ShotAI.exe` 同级目录存在 `runtime/image/sd-server.exe`。
4. 启动 `ShotAI.exe`，进入“创作图片”，选择已经下载好的图片模型。

选择模型后，ShotAI 会把模型放到 `models/image`。以后启动时，只要图片组件和
模型都存在，就会自动启动图片服务，不需要手动切换聊天模型。

## 注意

- 这不是完整 ShotAI，不能单独运行，必须合并到 EXE 精简包或对话免安装包。
- 图片生成和图片识别是两项功能。图片识别由 Ollama 视觉模型完成，不依赖本包。
- 如果窗口提示“图片运行组件或图片模型未准备”，说明组件或模型至少缺少一个。
