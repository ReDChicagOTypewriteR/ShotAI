# 更新日志

## 1.4.1 · 文档分析与操作反馈

- 单份文档支持直接分析，内部摘要使用独立预算，减少模型往返。
- 分析草稿提前显示，停止后清除；复用重复操作，避免重复生成文件。
- 设置中增加自动分配、多卡分担和逐卡实例模式，保存后重启生效。
- 补充工具耗时、首字时间、思考与正文输出计量。
- 同步提供 Windows、Ubuntu DEB / AppImage 安装包。

## 1.4.0 · 模型运行与并发

- Ollama 升级至 0.40.16，保留 CUDA 12 运行组件。
- 优化文件结构化输出、推理兼容、模型驻留和状态缓存。
- 完善公平排队、取消、双卡实例与 GPU 进程归属。
- 增加构建编号、任务关联和日志轮转。

## 1.3.0 · 办公能力与可靠性

- 将 Excel、Word、PDF 处理整合进聊天，取消独立 Skill 入口与桌面宠物。
- 增加模型体检、导入诊断、桌面日志和完整清理。
- 优化多人排队、主机监控、文件交互与中英文界面。
- 统一双平台构建，图片运行组件改为可选扩展。

更早版本与安装资源见 [GitHub Releases](https://github.com/ReDChicagOTypewriteR/ShotAI/releases)。
