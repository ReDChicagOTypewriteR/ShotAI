# ShotAI Windows 1.2.0

适用系统：Windows 10/11 x86_64。完整安装包包含 Windows Ollama CUDA 12 和 Windows 图片运行组件，不包含 Qwen3.5、FLUX.2 或其他模型权重。

## 安装

1. 双击 `ShotAI-1.2.0-Windows-x64-Full-CUDA12-Setup.exe`。
2. 按安装向导选择位置并完成安装。
3. 从桌面或开始菜单启动 ShotAI。

安装程序默认保留已有模型和配置。ShotAI 完整版使用自己的 Ollama 端口和模型目录，避免与系统中单独安装的 Ollama 混用模型。

## 模型导入

- 选择 GGUF 后只快速检查文件结构，不再提前完整扫描大文件。
- 正式导入时只读取一次，同时写入并计算 SHA-256。
- 已存在的相同内容直接复用；失败原因写入桌面和运行日志。

## 五人并发

默认最多接收五条活跃对话请求：两条同时推理、三条等待，第六条提示稍后重试。当前聊天模型基线为 Qwen3.5；多人使用优先选较小的 Q4 量化版本，并将上下文从 8K 开始测试。

## 图片生成与修改

Windows 完整包包含图片运行组件，但不包含模型。导入 FLUX.2 Klein 9B 时需要主模型、Qwen3 8B 文字理解文件和 small decoder 三个文件。用户可以直接在对话中说“帮我生成一张图片”，也可以用“再加一点蓝色”等后续指令继续修改上一张图片。
