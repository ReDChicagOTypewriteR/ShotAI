# ShotAI 1.4.0 更新计划与任务清单

状态：开发实现及本机回归已完成一轮，Ubuntu / Windows 实机验收待完成（2026-11-12）。以下勾选项以代码和测试为依据，不代表服务器性能已验收。当前应用版本仍为 1.3.0，未生成或发布 1.4.0 安装包。

公共功能沿用 Ubuntu 实现基线，同时验证 Ubuntu 22.04 x86_64 与 Windows 10/11 x86_64。功能开发与发布整理到 `codex/unified`。

## 预期更新日志

- 升级 Ollama 运行组件，完善离线模型兼容性与升级回退。
- 优化 Excel、Word、PDF 的生成和连续修改，减少结构化输出与推理模式冲突。
- 优化模型驻留和上下文复用，减少同一任务各阶段的重复加载。
- 根据模型和运行组件的实际能力调度请求，完善公平排队、取消与双卡任务分配。
- 完善逐卡 GPU 状态，展示实际加载位置、运行后端与显存使用。
- 缓存模型详情并合并状态查询，减少重复轮询。
- 增加构建标识、任务阶段与进程退出诊断，完善日志轮转和诊断导出。

日志记录了 97 次语法解析失败，其中包含正文长度和数组重复展开超限。当前表格与文档工具也存在较大的嵌套上限。

- [x] 分离生成时使用的简化结构与 ShotAI 本地完整校验规则。
- [x] 简化发给运行时的字符串和数组约束，保留参数类型、必要字段与工具边界。
- [x] 对原生工具调用和 JSON 回退使用一致的本地校验。
- [x] 依据错误类型限制重试次数，并在兼容回退时保留用户要求和附件。
- [x] 按模型记住兼容降级；摘要、运行组件版本变化或手动刷新后重新探测。
- [x] 自动检查原文件保留、Word 回读、Excel 公式与修改范围，以及 PDF 页面结构。
- [ ] 真实 Qwen3.5 连续生成与追改验收；PDF 需人工检查页面内容和版式。

验收覆盖 Excel、Word、PDF，每种格式连续执行 10 轮生成与追改，覆盖自动推理及关闭推理。记录每轮结果，要求文件可打开、目标修改正确、任务可继续。增加独立的复杂语法回归用例，验证一次失败后的后续请求能够恢复。

本机已通过三种格式各 10 轮连续生成，交替自动推理 / 关闭推理，模型响应由测试控制、输出文件实际生成并执行本地检查。Word / PDF 修改、Excel 连续追改、语法失败恢复和跨格式输出也通过浏览器回归；不替代真实 Qwen3.5 的十轮生成与追改验收。
