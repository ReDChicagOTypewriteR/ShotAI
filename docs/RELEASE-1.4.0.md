# ShotAI 1.4.0

Ubuntu 22.04 x86_64 测试安装包。本轮不发布 GitHub，也不生成 Windows 安装包。

## 更新内容

- Ollama 升级至 0.40.16，保留 CUDA 12，排除 CUDA 13 和 Vulkan。
- 优化 Excel、Word、PDF 生成、连续追改、结构化输出和推理兼容回退。
- 统一任务上下文，减少重复加载；缓存模型详情并合并状态查询。
- 完善五客户端公平排队、取消恢复、图片任务独占及模型清理协调。
- 增加可配置的逐卡运行实例、GPU 进程归属与单卡 / 跨卡占用显示。
- 增加构建编号、操作关联、错误分类、文件校验记录和日志轮转。
- 修复安装后主进程读取外部日志模块和构建信息的路径。

## 测试状态

本机自动化已覆盖文件生成与修改、取消恢复、模拟双实例、故障恢复、双语界面及包内资源检查。Excel、Word、PDF 各通过十轮连续生成测试；模型响应使用模拟上游，文件实际生成并执行本地校验。

仍需 Ubuntu V100 实机验证 CUDA 12、真实 Qwen3.5、双卡五人负载、取消后的 GPU 停止情况及覆盖升级。Windows 实机验收另行进行。

安装包不包含模型权重、NVIDIA 驱动和可选图片运行扩展。普通升级保留已有模型、会话与配置；测试前建议备份数据。
