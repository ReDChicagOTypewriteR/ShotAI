# ShotAI Windows EXE 对话免安装包 · CUDA 12

这个版本面向 NVIDIA 显卡 Windows x64 主机，已经包含 ShotAI 原生启动器和
Ollama CUDA 12 免安装运行组件。它不包含任何聊天、图片识别或图片生成模型。

## 使用方法

1. 解压整个目录。
2. 双击 `ShotAI.exe`，允许管理员权限。
3. 浏览器会自动打开 `http://127.0.0.1:9090`。
4. 在主机网页中添加下载好的模型文件。
5. 其他电脑访问 `http://主机内网IP:9090`。

通过网页添加的模型统一保存在 `models/ollama`。复制整个 ShotAI 目录即可同时
迁移程序和模型。

双击后不会出现黑色控制台窗口。再次双击不会重复启动，只会重新打开工作台。
需要停止时执行 `ShotAI.exe --stop` 可以安全停止；后续版本会继续增加任务栏
退出入口。

## 为什么比完整包小

这个包只保留 4070 Ti 等 NVIDIA 显卡需要的 CUDA 12 运行文件，已经排除：

- CUDA 13 运行文件；
- Vulkan 运行文件；
- stable-diffusion.cpp 图片生成组件；
- 所有模型权重。

聊天、图片理解、文档和我的资料都可以使用。只有“生成图片”需要额外复制
图片生成运行组件到 `runtime/image`，并在网页中添加图片生成模型。

仓库可以通过 `npm run package:windows-image-runtime` 生成独立的可选图片组件包。
将包内 `runtime` 文件夹合并到本目录即可；该组件包仍然不会携带模型文件。

如果启动失败，请先看窗口中的明确提示，再查看 `logs/server.log`。新版会在启动
前检测 9090 是否已被旧版 ShotAI 或其他程序占用。

## 当前边界

- 需要支持 CUDA 12 的 NVIDIA 驱动；不适用于 AMD 显卡。
- 当前不会显示控制台窗口；后续可继续加入系统托盘和可视化退出入口。
- 本包在 macOS 上完成 Windows x64 交叉编译和文件结构检查，首次正式使用前
  仍需在 Windows 4070 Ti 主机验证启动、UAC、防火墙和模型推理。
